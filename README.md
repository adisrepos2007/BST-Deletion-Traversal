# Binary Search Tree – Deletion and Traversal

## Project Description
This project demonstrates Binary Search Tree (BST) operations using the C programming language, including tree construction, traversal, and node deletion.

## Features

- Level-order traversal
- BST node deletion
- Inorder successor method

## How to Run
Compile using:

```bash
gcc main.c -o bst
```

Run using:

```bash
./bst
```
